# Algorithmic Handbook

Welcome to the Algorithmic Handbook, a comprehensive, portfolio-grade repository covering data structures, algorithmic paradigms, and coding patterns.

**📚 Documentation:** All algorithmic roadmaps and python solutions have been moved to the `docs/` directory for MkDocs deployment.

To view the handbook locally, run:
```bash
pip install mkdocs mkdocs-material
mkdocs serve
```

For deployment instructions, please see [DEPLOYMENT_GUIDE.md](./DEPLOYMENT_GUIDE.md).
