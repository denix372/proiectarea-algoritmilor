SECTION 6: Flow Max Flow, Min Cut & Connectivity​

PATTERN 1: Classic Max Flow Ford-Fulkerson, Edmonds-Karp, Push-Relabel​

Concept: Pushing flow from Source to Sink along augmenting paths.

🌀 Niche​

  • Ford-Fulkerson Algorithm for Maximum Flow - GFG
  • Push-Relabel Algorithm - GFG
  • Download Speed - CSES 1694

PATTERN 2: Minimum Cut / Edge Cut​

Concept: By the Max-Flow Min-Cut theorem, the maximum flow equals the capacity of the minimum cut.

🔥 Standard​

  • Minimum Cut in a Directed Graph - GFG

🧩 Practice​

  • Police Chase - CSES 1695

PATTERN 3: Maximum Bipartite Matching​

Concept: Connect a super-source to set A and super-sink to set B with an edge capacity of 1, then run a flow algorithm.

🌀 Niche​

  • Maximum Bipartite Matching - GFG
  • School Dance - CSES 1696

🔥 Standard​

  • Hopcroft Karp Algorithm - GFG

PATTERN 4: Edge-Disjoint Paths & Edge Connectivity​

Concept: Assign capacity 1 to all edges. The max flow equals the max number of edge-disjoint paths or the minimum edges to disconnect the graph.

🧩 Practice​

  • Find Edge Disjoint Paths - GFG

🔥 Standard​

  • Distinct Routes - CSES 1711
  • Minimum Number of Edges to Disconnect Graph - GFG

PATTERN 5: Vertex Cut & Vertex-Disjoint Paths Node Splitting​

Concept: To constrain node capacity, split each vertex v into v_in and v_out with a directional edge between them of capacity 1.

🧩 Practice​

  • Find Maximum Number of Vertex-Disjoint Paths - GFG

🔥 Standard​

  • Minimum Vertex Cut (Node Splitting approach)
  • Network Connectivity (Vertex Version)
