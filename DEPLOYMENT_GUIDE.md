# 🚀 Deployment Guide: Docusaurus & GitHub Pages

This guide walks you through migrating your professional Algorithmic Handbook into **Docusaurus**, an optimized framework designed perfectly for structured documentation.

---

## 1. Prerequisites
Ensure you have **Node.js** (version 18.0 or above) and **npm** installed on your local machine. You will also need `git` to deploy the site to GitHub Pages via GitHub Actions.

---

## 2. Initialize Docusaurus Locally

To initialize a brand new Docusaurus repository, run the following command in the parent directory where you want your Docusaurus site to live (do **not** run this inside the existing `proiectarea-algoritmilor` folder if you want to keep them separate, or run it here and merge the folders):

```bash
npx create-docusaurus@latest website classic
```

This will create a new folder called `website/` with the default Docusaurus scaffold. Navigate into this directory:
```bash
cd website
```

To see the default site running locally, run:
```bash
npm run start
```
It will start a development server at `http://localhost:3000/`.

---

## 3. Migrate the Algorithmic Trackers

Docusaurus generates documentation from Markdown files placed in its `docs/` folder. It uses the prefixes (like `0_`, `1_`) to automatically order the sidebar.

1. **Delete the default Docusaurus docs:**
   ```bash
   rm -rf website/docs/*
   ```

2. **Move your numbered algorithmic domains:**
   Copy the `0_data_structures`, `1_common_techniques`, ..., `9_heuristic_algorithms` directories from this repository into `website/docs/`.

   *(If you are already inside the root of this repository, simply move the contents of `docs/` over to your Docusaurus `docs/` folder.)*

3. **Check the Sidebar:**
   Because Docusaurus supports autogenerated sidebars by default, simply migrating the prefixed folders (`0_ds`, `1_common_techniques`, etc.) will instantly build a beautifully organized, nested sidebar in Docusaurus.

---

## 4. Automating Deployment with GitHub Actions

Docusaurus supports seamless deployment to GitHub Pages via GitHub Actions.

1. **Create the Workflow File:**
   Inside your Docusaurus project (or the root of the repository if you merged them), create the directory `.github/workflows/` and add a file named `deploy.yml`.

2. **Paste the following configuration into `deploy.yml`:**

```yaml
name: Deploy to GitHub Pages

on:
  push:
    branches:
      - main
    # Review gh actions docs if you want to further scope it to the `docs` directory!

jobs:
  build:
    name: Build and Deploy Docusaurus
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
        with:
          fetch-depth: 0
      
      - uses: actions/setup-node@v3
        with:
          node-version: 20
          cache: npm
          # If your docusaurus is in a subfolder like `website`, point to it:
          # cache-dependency-path: 'website/package-lock.json'
          
      - name: Install dependencies
        run: npm ci
        # working-directory: ./website
        
      - name: Build website
        run: npm run build
        # working-directory: ./website
        
      - name: Deploy to GitHub Pages
        uses: peaceiris/actions-gh-pages@v3
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./build  # Use ./website/build if nested
          user_name: 'github-actions[bot]'
          user_email: 'github-actions[bot]@users.noreply.github.com'
```

3. **Configure the Base URL (Crucial):**
   Open `docusaurus.config.js` in your Docusaurus root folder. Update the following fields so assets load correctly on GitHub pages:
   ```javascript
   url: 'https://<YOUR_GITHUB_USERNAME>.github.io', 
   baseUrl: '/<YOUR_REPOSITORY_NAME>/', 
   projectName: '<YOUR_REPOSITORY_NAME>',
   organizationName: '<YOUR_GITHUB_USERNAME>',
   trailingSlash: false,
   ```

4. **Enable GitHub Pages settings:**
   Go to your repository settings on GitHub -> **Pages**.
   Under **Build and deployment**, change the **Source** to `gh-pages` (this branch will be created automatically by the Action once you push).

5. **Commit and Push:**
   Push your changes to the `main` branch. GitHub Actions will pick it up, build the static Docusaurus site, and deploy it flawlessly to GitHub Pages!
