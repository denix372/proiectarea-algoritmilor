Backtracking — Complete Roadmap

This is the complete list of backtracking problems, organized by phases.
Use the GitHub Issue for tracking progress.

PATTERN 1: The Core Three (Subsets, Permutations, Combinations)​

These are the building blocks of almost all backtracking.
Master these before moving on.

🔥 Standard​

  • Subsets
  • Permutations
  • Combinations
  • Combination Sum
  • Arrangements/ K-Permutations — Permutations with length K
  • Cartesian Product between lists

🧩 Practice​

  • Subsets
  • Permutations II (With duplicates)
  • Combination Sum II (With duplicates, use each once)
  • Combination Sum III
  • Letter Combinations of a Phone Number - Leetcode 17 https://leetcode.com/problems/letter-combinations-of-a-phone-number/
  • Generate Parantheses — Leetcode 22 https://leetcode.com/problems/generate-parentheses/description/
  • Power Set in Lexicographic Order

🌀 Niche​

  • K-th Permutation Sequence
  • Combination Sum IV (DP problem but good recursion practice) — LeetCode 377
  • String generation with frequency and K consecutive constraints — Romanian
  • Permutations of a String (Lexicographic order)

PATTERN 2: Constraint Satisfaction & Board Games​

🔥 Standard​

  • N-Queens
  • Word Search
  • Rat in a Maze
  • Sudoku Solver

🧩 Practice​

  • N-Queens II - LeetCode 52
  • M-Coloring Problem
  • N-Queen in O(n) space — GFG
  • Knight’s Tour (Warnsdorff heuristic) — GFG
  • Knight’s Tour — CSES 1689
  • Unique Paths III

🌀 Niche​

  • Solving Cryptarithmetic Puzzles (SEND + MORE = MONEY)
  • Hamiltonian Cycle — GFG
  • Magnet Puzzle — GFG
  • Sudoku (Print all solutions) — GFG
  • Gray Code
  • Tiling Rectangle

PATTERN 3: Partitioning & Optimization​

These problems involve splitting strings or sets into valid pieces.

🔥 Standard​

  • Palindrome Partitioning
  • Word Break I (Backtracking version first)
  • Word Break II

🧩 Practice​

  • Partition to K Equal Sum Subsets
  • Subset Sum (Backtracking version first)
  • Remove Invalid Parentheses — LeetCode 301 / GFG
  • All Palindromic Partitions (with memoization)

🌀 Niche​

  • Word Squares
  • Tug of War
  • All Longest Common Subsequences in Lexicographical Order — [GFG](

PATTERN 4: Pathfinding & Complex Exploration​

Harder problems involving distance, safety, or complex state tracking.

🔥 Standard​

  • Rat in a Maze with multiple jumps
  • Combinational Sum/Target Sum Combinations (Variation of standard combination sum) — GFG https://www.geeksforgeeks.org/dsa/combinational-sum/

🧩 Practice​

  • Longest Possible Route in a Matrix with Hurdles
  • Shortest Safe Route with Landmines (Backtracking version first)
  • Maximum Number Possible with at-most K Swaps — GFG

🌀 Niche​

  • Paths from corner cell to middle cell
  • All paths between two vertices (Graph Backtracking)
  • Path of more than k length from a source
  • All paths from a given source to a destination — GFG

PATTERN 5: Advanced Constraint Pruning Niche Layer​

specific or advanced competitive programming techniques.

  • N-Queens with AC3 (Arc Consistency Algorithm)
  • Check for Sum-String — GFG
